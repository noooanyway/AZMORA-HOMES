# Pendências do catálogo Azmora Homes

Relatório de revisão das 16 fichas a partir do JSON e do CSV do pacote de pesquisa e da verificação anterior dos anúncios individuais. A correspondência foi feita pelo **ID e URL do anúncio**. O ID do site identifica a unidade até a Azmora atribuir uma referência comercial. Os dados de modelos comparáveis ficaram fora das fichas.

Para cada pedido, enviar ao Ruben o ID e o link indicados abaixo. Para dimensões, pedir comprimento e largura medidos na própria unidade. Para a área, indicar separadamente interiores, área de implantação e terraço, quando existir. A separação entre a cabine de duche e a sanita não determina o número de casas de banho completas.
